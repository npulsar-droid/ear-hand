# Ear & Hand — 耳と手で覚える音楽理論

コード・スケール・音程を、**聴いて当てる（耳）** と **弾いて答える（手）** の
2方向から叩き込むドリル。MIDIキーボードを繋げば、実際に鍵盤を押して回答できます。

音楽理論の本を読んでも和音が聴き取れるようにはならないし、
コード表を眺めても指は動きません。そこを埋めるための練習台です。

**単一HTMLファイル・依存ゼロ・ビルド不要。** ダウンロードしてダブルクリックで動きます。

全5章12レッスン（音程 → 三和音 → 四和音 → スケール/モード → コード進行）。

## 2種類のレッスン

**耳レッスン（👂）** — 「▶ 聴く」を押して、鳴った音を選択肢から選ぶ。
音程、三和音の種類、セブンス、スケールなど。

**手レッスン（🎹）** — 提示されたコードやスケールを実際に弾く。入力は3通り:

- MIDIキーボード（接続されていれば自動検出）
- 画面上の鍵盤をクリック
- PCキーボード（`A`〜`K` が白鍵、`W E T Y U` が黒鍵）

**オクターブと転回は自由**です。構成音（ピッチクラス）が揃っていれば正解になります。
C-E-G を弾いても E-G-C を弾いても、どちらも C メジャーとして通ります。

## 出題の仕組み

一発正解のみカウントします。間違えた問題はそのセッションの少し後に再出題され、
次回以降も出やすくなります。正答率は表示しません
——「間違えた問題ほど早く戻ってくる」だけの、軽い間隔反復です。

第5章の最後は卒業課題「**好きなキーで ii–V–I**」。キーは弾いた内容から自動判定するので、
得意なキーで弾いて構いません。三和音でもセブンスでも通ります。

## 動かす

そのまま開くだけです。

```bash
open index.html
```

ローカルサーバ経由でも動きます。

```bash
python3 -m http.server 8321
```

> **注意**: `file://` で開いた場合と `localhost` で開いた場合では、
> ブラウザの localStorage の保存先が別になります。進捗を続けたいなら開き方を統一してください。

### ブラウザ

Web Audio API と Web MIDI API を使います。MIDI入力は Chrome / Edge で動作します
（Safari と Firefox は Web MIDI 非対応 —— 画面鍵盤と PCキーボードは問題なく使えます）。

## テスト

```bash
node test.js
```

`index.html` 内の `/*THEORY-START*/ 〜 /*THEORY-END*/`（判定ロジックの純粋関数部）を
抽出して、転回の許容・キー判定・ii–V–I の成立条件など35件を検証します。
ブラウザも npm も要りません。

## 技術

- 音: Web Audio API（三角波オシレータ＋エンベロープ。音源ファイルなし）
- 入力: Web MIDI API ＋ 画面鍵盤フォールバック。
  卒業課題では「全鍵盤を離した時点」でコードを確定します
- 保存: localStorage（`ear-hand-v1`）。サイドバー下からリセット可
- 外部ライブラリなし
